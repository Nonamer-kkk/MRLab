# 焦耳定律短路起火实验设计

## 实验目标

将 `Q = I²Rt` 转化为可观察的电流、温升、烟雾和起火过程，让学习者完成“巡检—设参—触发—处置—复盘”闭环并解释事故原因。先交付 Windows PC 单人单线路版本，保留 MR/CAVE 场景和交互目录，后续复用同一实验核心。

## 实验场景与器材

正式场景：`Assets/_Project/Scenes/PC/01_PC_Main.unity`。环境为室内电工实验室，不模拟宿舍。1 Unity Unit = 1 米。

| 器材 | 用途 |
| --- | --- |
| 实验台、墙面、警示牌 | 容纳线路并提供实验区域与安全提示 |
| 配电箱、主开关、保护器、接线端子 | 供电、保护动作和隔离故障 |
| 铜芯导线、绝缘层、负载、短路支路和接触点 | 单线路实验对象 |
| 报警器、断电点、灭火器 | 完成安全处置 |
| 参数面板、电流/温度曲线、回放时间轴 | 观察、设参、复盘和结果导出 |

主场景保留 `_Systems`（ExperimentManager、UIManager、AudioManager、InputManager、ResetManager）、`_Environment`、`_Experiment`（Devices、Materials、Interactables、Effects）、`_Interaction/PC`、`_UI`、`_Camera`、`_Debug`。

## 操作步骤

1. 巡检线路、负载、保护器和断电点。
2. 设定线径、负载、接触电阻和保护器状态；进入选点模式，在四条实验导线上连续点选/拖动故障位置。
3. 通电观察正常状态，再触发短路或接触不良。
4. 先断电/隔离，再报警。拖动灭火器到合适位置、调整喷嘴方向，再持续按住开关瞄准火焰根部喷射。未断电时的错误操作说明原因并允许重试。
5. 查看电流/温度曲线、关键事件和因果链回放，与上一轮比较并导出 CSV。

## 物理模型与实验结果

电路层采用 `I = U / R_total`，导线与接触点的发热采用 `P = I²R`，热学层采用 `ΔT = (P - cooling) × Δt / C`。短路支路旁路负载，使回路电流显著增加。PPT 的“五倍电流、二十五倍产热”仅说明平方关系，不是固定实验结果。

实时集总参数模型用于教学趋势验证，不替代专业消防鉴定或有限元热分析。材料阈值是仿真参数，不能作为现实材料的消防判据。视觉连续表现完好、变色、软化、热解、烟雾、明火和碳化，不把短路做成一次爆炸。PPT 中 `20 °C`、`90 °C`、`250 °C+` 为示意温标，实际显示以模型参数为准。

结果应包含实验参数、故障类型、触发/隔离/报警/灭火事件、电流与温度记录、材料状态以及处置评价。线径、负载、接触电阻和保护器变化应在数值、曲线与视觉状态中呈现一致的变化趋势。

故障点以导线编号 `FaultWire`（0 供电正线、1 试验线、2 负载正线、3 回线）和沿线距离比例 `FaultPosition`（0–1）记录，不再使用三个离散预设点。编号和比例随每个历史样本保存，热点、烟火、回放和 CSV 采用同一位置。本轮通电后锁定选点，避免在同一条曲线中途移动故障；重置后可在新一轮自由选点。自由选点限于真实存在的导线，空白桌面不产生电气故障。当前仍是单一局部集总热模型，改变点位不等于建立整条线路的分布式温度场。

灭火使用连续抑制进度：必须已隔离、已报警、仍有明火，并且喷嘴处于有效方向和距离，持续按住开关时才累计；约 3 个仿真秒有效喷射后转为碳化状态。瞄偏或松开只暂停累计，暂停仿真不积累进度。有效喷射范围和命中由空间交互层根据喷嘴与当前热点判断；热学模型不读取鼠标。一次点击、旧快捷命令和 UI 按钮均不能跳过持续操作直接完成灭火。

PC 操作中，左键拖动瓶身在观察平面内移动，拖动时滚轮控制前后深度；持有时在三维空白处左键拖动调整喷嘴方向，松开保留方向以便操作 UI 喷射开关。三维区域按住右键则随鼠标同时瞄准和喷射。拿取/收回按钮和 `X` 可切换持有状态，`Escape` 归还器材；未持有灭火器时右键与滚轮恢复环绕和缩放观察。

明火燃料耗尽窗口由旧版 30 个仿真秒延长至 180 个仿真秒，给拿取、移动、瞄准与练习留出时间。这个时间是教学交互参数，不代表真实材料燃烧时长；未处置时仍会自然耗尽，断电不立即熄火，灭火后仍需观察余热。

## 架构与流程关系

`JoulePCInput` 位于 `Scripts/Interaction/PC`，集中处理 Unity Input System 鼠标和键盘，把屏幕射线转换为世界坐标、拖动和扳机状态。`WirePathGeometry` 提供四条导线的连续几何点和最近点查询。`ExtinguisherInteraction` 提供输入无关的拿取、移动、瞄准、开关、释放和归位接口，计算喷嘴对热点的有效命中；不直接读取 PC 按键。UI 位于 `Scripts/UI`，显示数据并提交操作。`JouleModel` 与 `JouleExperimentManager` 负责数学模型、状态、流程判断、持续灭火进度、结果、记录与 Reset；核心不直接读取屏幕坐标、鼠标或键盘。

PC 鼠标/键盘 → 世界空间交互接口 → 实验核心 → 状态/结果事件 → UI、曲线与三维现象。后续 VR 可将手柄抓取姿态传入移动接口、手柄或喷嘴姿态传入瞄准接口、扳机状态传入持续喷射接口；射线或直接触碰导线可复用最近点查询。PC 的拖动平面、滚轮深度和视角环绕只是 PC 适配器的操作方式，不成为实验核心前提。本次未安装 XR 插件或实现头显控制器绑定，后续仍需完成抓取姿态、碰撞/可达范围与头显实测。

## 实验结束条件与 Reset

故障发生后隔离电源，并完成报警/灭火处置或保护动作复盘，本轮进入复盘。任意阶段均可重置：恢复线路和器材初始状态，归还灭火器并停止喷射，清除本轮灭火进度、报警、烟雾、火焰、计时、曲线和回放状态，允许再次实验。选定的实验参数和故障点保留，方便对照试验；上一轮样本内的位置不随新一轮选择改变。已导出的 CSV 不因 Reset 删除。

## 项目创新点

- 热风险叠加：导线和故障点以温度梯度显示危险位置。
- 因果链回放：按时间回看参数、电流、温度、材料状态和视觉现象。
- 对比实验：比较本轮与上一轮曲线，解释保护器和参数变化的影响。
- 安全顺序反馈：错误操作给出具体原因并允许重试。

## 阶段验收

以单线路五步流程、物理趋势、全部状态 Reset、中文字体与曲线/回放为功能验收重点。PC 60 FPS 为目标，须实际测量后记录。实验室硬件相关的 MR、CAVE 同步与教师故障注入不在本次 PC 交付范围。
