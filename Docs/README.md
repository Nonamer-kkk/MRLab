## 启动

用指定 Unity 版本打开工程，再打开 `Assets/_Project/Scenes/PC/01_PC_Main.unity` 运行。正式 Windows x86-64 程序输出在 `Builds/PC`。集成后的构建和启动结果以 `PCValidation.md` 为准。

## 操作

按界面提示完成巡检，选择线径、负载、接触电阻和保护器。通电前进入选点模式，在供电正线、试验线、负载正线或回线上左键点选/拖动，沿整条导线连续设定故障点。通电后触发短路或接触不良；本轮开始后固定故障点，重置后可重新选点。

发生明火后，先断电/隔离并报警，再用左键拖动灭火器瓶身（也可按拿取按钮）。拖动时滚轮调节前后距离，在三维区域的空白处按住左键拖动来瞄准火焰根部；松开左键保留喷嘴方向，可以移到界面的喷射开关上按住喷射。也可在三维区域按住右键，一边移动鼠标瞄准一边喷射。只有有效命中才积累灭火进度，累计约 3 个仿真秒后扑灭；松开开关、瞄偏或暂停时不增加进度。灭火器不会因单击或快捷键立即扑灭火焰。最后查看电流/温度曲线、因果链回放、上一轮比较，或导出 CSV。

| 快捷键/鼠标 | 功能 |
| --- | --- |
| `P` | 通电/断电 |
| `F` | 触发短路 |
| `G` | 触发接触不良 |
| `E` | 紧急隔离 |
| `A` | 报警 |
| 左键拖动灭火器瓶身 | 拿取并移动灭火器 |
| 拖动灭火器时滚轮 | 调整前后距离 |
| 持有灭火器时在三维区域空白处左键拖动 | 调整喷嘴瞄准方向，松开保留方向 |
| 持有时在三维区域按住右键 | 随鼠标瞄准并持续喷射，松开即停 |
| 按住界面喷射开关 | 沿保留的方向持续喷射，松开即停 |
| `X` / 拿取、收回按钮 | 拿取或归还灭火器 |
| `Escape` | 退出操作模式并归还灭火器 |
| `T` | 热风险叠加 |
| `R` | 重置实验 |
| `Space` | 暂停/继续 |
| 未持有灭火器时右键拖动 / 滚轮 | 环绕观察 / 缩放 |
| `Home` | 镜头复位 |

流程操作保留 UI 按钮；空间位置、器材移动、瞄准和持续喷射由用户直接控制。实验核心不读取鼠标、屏幕坐标或特定按键，后续 VR 控制器通过同一交互接口传入世界坐标和扳机状态。复盘通过时间滑条查看记录；每个样本保留故障导线编号和沿线归一化位置，CSV 同步导出这两个字段。CSV 导出位置为 `Application.persistentDataPath/Results`，本机为 `C:/Users/71076/AppData/LocalLow/MRLab/JouleLab_E10/Results`。长路径在界面可能省略，文件名以该目录中的 CSV 为准。

## 已知问题与边界

- 按用户要求保留当前工程路径 `E:\Unity Project\MRLab_E10_24371119`。
